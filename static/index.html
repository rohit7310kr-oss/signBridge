Fingerspelling recognition (ASL)

Recognizes ASL fingerspelling (letters spelled by hand) only. It does not translate ASL signs or sentences. Pressing “Stop & recognize” sends landmark numbers (no video) to three.ws through this local server. Capture uses the same HandLandmarker as the recorder, so the hands you see while capturing are the hands you would export; the Holistic detector is added only for the face/pose columns the API schema asks for.

Start the camera, then press “Start capture” and spell a word.
